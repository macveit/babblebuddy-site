# lunatic-enterprises-site

Static one-page website for `lunatic-enterprises.de`.

## Structure

```text
lunatic-enterprises-site/
  index.html
  impressum.html
  datenschutz.html
  assets/
    css/
      styles.css
```

## Usage

Open `index.html` directly in a browser. No build step, framework, external assets, tracking, cookies or third-party dependencies are used.

## Notes

- The DE/EN switch is implemented with minimal inline vanilla JavaScript on the static page.
- `impressum.html` and `datenschutz.html` intentionally contain clearly marked placeholders and must be reviewed before publication.
- The BabbbleBuddy project link currently points to `https://babbblebuddy.com`.
